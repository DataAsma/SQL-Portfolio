# Buyer Analysis Project
## Project Overview:

This is a beginner SQL project focused on analyzing buyer information and purchasing behavior using Microsoft SQL Server.
The project uses a sample dataset of 8 buyers from 4 different countries to explore buyer demographics and purchasing patterns.

## Dataset Description
The `buyers` table consists of the following columns:

- buyer_id: Unique identification number for each buyer (primary key).
- first_name: Buyer's first name.
- last_name: Buyer's last name.
- age: Buyer's age (can contain NULL values).
- country: Buyer's country.
- email: Buyer's email address.
- purchase_amount: Amount spent by each buyer.

## Objectives
- Explore buyer demographics.
- Identify purchasing patterns across different countries.
- Calculate total and average purchase amounts.
- Identify the countries with the highest and lowest purchase amounts.

## Tools Used
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)

## SQL Skills Demonstrated
- SELECT and FROM
- WHERE
- AND and OR
- ORDER BY
- TOP
- DISTINCT
- Aggregate functions (COUNT, SUM, AVG, MIN, MAX)
- GROUP BY
- HAVING

## Key Findings
1. The database contains 8 buyers from 4 different countries.
2. The total purchase amount is $8,300.00.
3. The average purchase amount is $1,037.50.
4. The USA recorded the highest total purchase amount ($3,500.00).
5. Nigeria recorded the lowest total purchase amount ($1,200.00).
6. The oldest buyer is Aisha Wale (56), from Nigeria.
7. The youngest buyer is Fatima Zakky (20), from Canada.
8. Canada, UK, and USA have average purchase amounts above $800.00.

## Conclusion
This project provided practical experience in using SQL to retrieve, filter, organize, and analyze data. It also demonstrated how SQL queries can be used to answer basic business questions about buyer demographics and purchasing behavior.
